ExtintorScan

Lectura asistida de etiquetas y registro de extintores

1. Capturar etiqueta

Subí una foto clara o usá la cámara. Para mejores resultados, encuadrá la etiqueta completa o el código QR.

Elegí una imagen para comenzar.

El OCR se ejecuta en el navegador mediante Tesseract.js y la lectura QR mediante jsQR.

2. Resultado del reconocimiento

A la espera de una imagen

Texto leído

3. Ficha del extintor

Los campos se completan automáticamente cuando el programa encuentra datos reconocibles. Revisalos antes de guardar: el OCR puede confundir letras, números y fechas.

4. Registros guardados en este navegador

Los registros se guardan localmente en este navegador y se envían a Google Sheets.

Todavía no hay fichas guardadas.

Cómo funciona el modelo incremental

Incremento 1

Captura de imagen desde archivo o cámara.

Incremento 2

OCR para leer el texto de la etiqueta o QR.

Incremento 3

Interpretación de campos conocidos y revisión manual.

Incremento 4

Guardado local y exportación de fichas.

ExtintorScan · Prototipo educativo. No certifica el estado del extintor ni reemplaza la revisión de un profesional habilitado.
